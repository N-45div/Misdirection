# Trailer (under 3:00)

The rules allow footage from a Meta device, the XR Simulator, or an equivalent emulator. No AI-generated video. Judges don't have to watch past 3:00, so the core rule must land in the first 30 seconds. Burned-in captions, licensed music, public on YouTube.

**The split screen is the product spec:** the headset view of the crowd's eyes next to an external camera on the real hands. If that clip doesn't make an outsider grin by Day 4, the fun gate has failed.

| Time | Shot | What it proves |
|---|---|---|
| 0:00–0:08 | Cold open in passthrough: the player glances at a spectator, the coin vanishes, the crowd gasps. Title: "Where you look, they look" | Hook, innovation |
| 0:08–0:30 | Split screen: headset view + external camera on real hands, with Magician's Eye cones following the look source | The core rule in 20 seconds |
| 0:30–1:05 | Launch, palms on the table, mentor ghost hands, first applause, no text | First Five Minutes, onboarding |
| 1:05–1:45 | A full show beat: produce-from-ear by gaze + pinch, then the Skeptic catching a careless ditch | Core loop and stakes |
| 1:45–2:05 | Robustness: a hand leaves view, freezes, tints and resumes; a second room; the no-table fallback | Technical Implementation |
| 2:05–2:25 | Daily crowd, the returning Regular, trick book, leaderboard; one-handed mode and voice "Look!" | Reason to Come Back, accessibility |
| 2:25–2:45 | Tech card over a Simulator clip in the VR Glasses profile: "Hands-only · Unity 6 + Meta XR SDK v207 · ISDK gaze · MRUK + anchors · FoV-tested · 72 fps on Quest 3S" | Rubric checklist |
